No current term set. Create one at /terms and mark it as Current before importing the schedule.

Each card accepts .csv or .xlsx. Header row required. Click Template to download a sample CSV — open it in Excel and save as .xlsx if you prefer that format.

1. Students Template

Required: matricol_number, full_name, email, year_of_study, group_name

Sets each student's primary group too (replaces the old Enrollments import).

2. Professors & Courses Template

Required: prof_full_name, course_code, course_name
Optional: prof_title, prof_email, role (PRIMARY/ASSISTANT)

One row per (professor, course). Upsert by prof_email else prof_full_name.

3. Schedule Template

Required: group_name, course_code, weekday, start_time, end_time, room_name

Attaches to the current term. weekday = MONDAY..SUNDAY. start/end = HH:mm. Course must already exist (upload professors first).
